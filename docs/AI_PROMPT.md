# Промпт для создания Deals Platform в ИИ

## Описание проекта

Создай полнофункциональное веб-приложение "Deals Platform" - платформу для заключения пари между пользователями с системой наблюдения и разрешения конфликтов.

## Технический стек

### Backend
- **Java 17** с Spring Boot 3.2.0
- **Spring Security** с JWT аутентификацией
- **Spring Data JPA** с Hibernate
- **H2 Database** (in-memory для разработки)
- **Maven** для управления зависимостями
- **Swagger/OpenAPI** для документации API

### Frontend
- **Vanilla JavaScript** (без фреймворков)
- **HTML5** с семантической разметкой
- **CSS3** с современным дизайном
- **Bootstrap 5** для UI компонентов
- **HTTP Server** (Python или Node.js) для локальной разработки

## Основные функции

### 1. Система аутентификации
- Регистрация пользователей (email + password)
- Вход в систему с JWT токенами
- Защищенные эндпоинты для авторизованных пользователей

### 2. Управление пари
- Создание пари с описанием, временем начала и длительностью
- Присоединение к пари как участник или наблюдатель
- Автоматическое изменение статуса пари по времени
- Система голосования участников

### 3. Система наблюдения
- Наблюдатели могут принимать финальные решения
- Разрешение конфликтов между участниками
- Логирование всех действий и решений

### 4. Статусы пари
- `OPEN` - открыто для присоединения
- `IN_PROGRESS` - активно
- `IMPLEMENTED` - завершено успешно
- `CONFLICT` - конфликт между участниками
- `RESOLVED` - конфликт разрешен наблюдателем

## Структура базы данных

### Таблицы
1. **users** - пользователи системы
2. **deals** - пари
3. **deal_participants** - участники пари
4. **deal_observers** - наблюдатели пари
5. **deal_votes** - голоса участников

### Связи
- Один пользователь может быть участником многих пари
- Один пользователь может быть наблюдателем многих пари
- Каждое пари имеет создателя и может иметь участников и наблюдателей

## API Endpoints

### Аутентификация
- `POST /api/auth/register` - регистрация
- `POST /api/auth/login` - вход

### Пари
- `GET /api/deals` - список всех пари
- `POST /api/deals` - создание пари
- `GET /api/deals/{id}` - детали пари
- `POST /api/deals/{id}/join` - присоединение к пари
- `POST /api/deals/{id}/vote` - голосование
- `POST /api/deals/{id}/observer-decision` - решение наблюдателя
