# 🔐 Тестовые данные Deals Platform

## 📋 Обзор

Система автоматически создает тестовых пользователей и пари при каждом запуске через `DataInitializer.java`. Это позволяет сразу начать тестирование без необходимости ручного создания данных.

## 🔄 Жизненный цикл тестовых данных

### Создание при запуске
```java
@Component
public class DataInitializer implements CommandLineRunner {
    
    @Override
    public void run(String... args) throws Exception {
        // Создаем тестовых пользователей
        if (userRepository.count() == 0) {
            createTestUsers();
        }
        
        // Создаем тестовые пари
        if (dealRepository.count() == 0) {
            createTestDeals();
        }
    }
}
```

### Условия создания
- **Пользователи**: создаются только если база пуста
- **Пари**: создаются только если база пуста
- **При перезапуске**: данные пересоздаются (H2 in-memory)

### Автоматические связи
- **Создатель пари**: автоматически становится участником
- **Время старта**: рассчитывается относительно времени запуска
- **Статусы**: устанавливаются в зависимости от времени

## 🚨 Решение проблем

### Пользователи не создаются
- Проверить логи Spring Boot
- Убедиться, что база данных доступна
- Проверить аннотации в `DataInitializer.java`

### Пари не отображаются
- Проверить статус пари
- Убедиться, что время старта корректное
- Проверить связи в базе данных

### Ошибки аутентификации
- Проверить правильность email/пароля
- Убедиться, что пользователь создан
- Проверить JWT токен
